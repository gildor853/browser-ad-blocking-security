# Security policy

## Supported versions

Only the `main` branch and the latest `1.x` release are maintained.

## Reporting a problem

This repository contains documentation, configuration examples and small
helper scripts. If you find an error with security impact, please report it
privately through GitHub's private vulnerability reporting rather than in a
public issue. Examples are a wrong extension ID, a policy example that weakens
protection, or a DNS endpoint that has changed hands.
<https://github.com/gildor853/browser-ad-blocking-security/security/advisories/new>
(repository **Security** tab → **Report a vulnerability**).

Ordinary corrections (typos, outdated links) can go in a normal issue.

## Scope

In scope: incorrect identifiers, policy names, registry paths or endpoints
in the documents, and problems in the scripts under `scripts/`.
Vulnerabilities in third-party products named here (browsers, extensions,
DNS services) should be reported to their vendors.
